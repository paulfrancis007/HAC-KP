ACPIA

Agentic Child Protection Investigation Assistant

Overview

ACPIA is a proof-of-concept AI-powered investigation assistant that helps investigators analyze digital evidence efficiently using a modular multi-agent architecture.

The system demonstrates how specialized AI agents can collaborate to extract entities, correlate information, reconstruct timelines, visualize relationships, and generate investigation summaries while keeping human investigators in control.
